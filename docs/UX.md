# UX & Usability Goals

GreenSpace Lite aims to provide a frictionless, intuitive plant management experience. The user interface (UI) and user experience (UX) are built around the following goals:

## 1. Core Usability Principles
- **Simplicity & Clarity:** A clean, uncluttered dashboard where plant statuses (healthy vs. needs water) are immediately identifiable at a glance.
- **Low Interaction Cost:** Users should be able to update a plant's watering status with a single click directly from the dashboard.
- **Visual Feedback:** Instant confirmation messages (toast notifications or status updates) when a plant is added, watered, or deleted.

## 2. Design Guidelines
- **Color Palette:** Nature-inspired tones (soft greens, earthy neutrals, and clear status accents like 🟢 green for healthy and 🔴 red for attention needed).
- **Responsive Layout:** Clean CSS structure that adapts smoothly to both desktop and mobile viewports.
- **Accessibility:** High-contrast text legible for all users and clear interactive button labels.
