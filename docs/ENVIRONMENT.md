# Development Environment & Tooling

To ensure consistency and ease of setup across development environments, the following stack and tools are used for GreenSpace Lite:

## 1. Core Stack
- **Programming Language:** Python 3.10+
- **Web Framework:** Flask
- **Database:** SQLite3 (embedded)
- **Testing Framework:** `pytest`

## 2. Developer Tools & IDE
- **IDE:** Visual Studio Code (VS Code)
- **Version Control:** Git & GitHub (HTTPS + Personal Access Token)
- **Process Management:** GitHub Projects (Scrumban Board)

## 3. Local Setup Requirements
- Python environment with `pip`
- Virtual environment (`venv`) for isolated dependency management
