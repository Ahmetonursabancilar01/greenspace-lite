# Method Choice and Rationale

We chose an **Iterative and Incremental delivery approach (Scrumban hybrid)** for GreenSpace Lite. 

- **Why this approach?** Because requirements for the UI and exact feature details can have minor adjustments, delivering in short, focused iterations (Sprint 1, 2, 3) allows us to inspect working software frequently, minimize late learning costs, and manage risks early.
- **Evidence of Process:** All work items, tasks, and bugs are managed transparently through the GitHub Projects Kanban board, broken down from a prioritized product backlog.
